# Kernel Panic — Game Overview

**Kernel Panic** is a tactical, turn-based roguelike in a Neuromancer-inspired cyberpunk setting. It focuses on resource management, social standing (Vouching), and the tension between physical survival and digital intrusion.

## Layered experience

- **Meatspace:** Industrial zones, cover, line-of-sight, corp threats (Phase 1 focus).
- **Cyberspace (later):** Matrix nodes, ICE, jack-in vulnerability — your body is defenseless while online.

## Presentation

ASCII-forward “terminal” UI on canvas: grid playfield, diagnostics sidebar, and tactical log — see [kernel-panic-v1-blueprint.md](kernel-panic-v1-blueprint.md) for mechanics and roadmap.
